# Polyglot AI

Build a premium, modern, responsive AI translation

application called Polyglot AI.

Tagline: Understand the world. Speak without barriers.

DESIGN:

- Minimalist, elegant, professional global SaaS product.

- Beautiful typography, generous spacing and subtle animations.

- Clean light interface with a sophisticated indigo accent.

- Fully responsive desktop and mobile layouts.

- Prioritize simplicity and usability.

LANGUAGES:

English, French, Arabic, Spanish, German,

Italian and Chinese (Simplified).

Support RTL layout for Arabic.

THREE CORE FEATURES:

1. TEXT TRANSLATION

- Source and target language selectors.

- Text input and translation output panels.

- Swap languages, copy and clear controls.

- Natural, context-aware translation.

2. VOICE TRANSLATION

- Microphone interaction.

- Recording state and audio waveform.

- Recognized speech and translated result.

- Playback of translated speech.

3. CAMERA TRANSLATION

- Camera capture and image upload.

- Image preview.

- Extracted original text and translated result.

ARCHITECTURE:

- React, TypeScript and Tailwind CSS.

- Prepare a clean API integration layer for a

  Node.js backend connected to Ollama and Gemma 4 E4B.

- Do not use external paid translation APIs.

- Do not fake successful AI translations.

- Use clearly labelled demo states until backend

  integration is complete.

Build a polished, functional frontend with

reusable components and clean code.
